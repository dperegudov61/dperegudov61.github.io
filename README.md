# dperegudov61.github.io

Личная страница проектов Перегудова Дмитрия Владимировича.

- Адрес: https://dperegudov61.github.io/
- Ссылка на вход в AI-чат: https://dperegudov61.github.io/AI-bot-chat/

Файл `index.html` — единственная страница. Публикуется скриптом
`publish_home.ps1` из проекта AI (`home\`). Репозиторий называется ровно
`dperegudov61.github.io` — тогда GitHub Pages отдаёт его с корня домена.

Раньше репозиторий звался `main-page`, поэтому страница жила по адресу
`/main-page/`; после переименования (23.11.2026) этот адрес отдаёт 404.

Обновление страницы: правим `home\index.html` → `.\publish_home.ps1` →
через полминуты смотрим https://dperegudov61.github.io/
