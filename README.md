# dperegudov61.github.io — общие страницы

Репозиторий: `dperegudov61/dperegudov61.github.io`
Адрес: **https://dperegudov61.github.io/**

Здесь лежит всё «общее» — то, что не зависит от того, включён ли домашний ПК:

| адрес | что там | файл |
|---|---|---|
| `/` | домашняя страница проектов: проверяет сервер и вход, кнопки неактивны без туннеля; по имени открывается `/account/`, плашка «Админка» видна только администратору | `index.html` |
| `/accounts/` | вход и личные ссылки `‎/accounts/<ключ>`; если вход уже есть — сразу уводит в чат | `accounts/index.html` |
| `/account/` | настройки своего аккаунта: ник, новый пароль (два поля), выход, удаление учётной записи. Ссылку и тип учётки здесь не выдают — только владелец | `account/index.html` |
| `/status.json` | список мостов — адрес туннеля, его пишет `tunnel.ps1` | `status.json` |
| `/404.html` | копия страницы входа: Pages отдаёт её на любой неизвестный путь | генерируется при публикации |

Плюс иконки и `manifest.json`: страница ставится на Android как приложение (PWA).

Тема, язык и шапка у всех страниц — общий шаблон `site\ui\` (`ui.js`, `ui.css`, `strings.tsv`,
`logo.png`; адрес `https://dperegudov61.github.io/ui/`) и таблица `strings.tsv` в каждой папке:
надписи лежат по-английски и помечены индексами, переводы — в таблице
(столбцы: индекс, en, ru — новый язык = новый столбец). В шапке — знак сайта (ссылка на
главную), значок темы, список языка (две буквы) и кнопка аккаунта. Выбор хранится
в `localStorage` и на сервере в `data\users\<id>\prefs.json`. Шаблон один на весь сайт:
копий в других репозиториях нет, `theme.js` там — пустая обёртка под старые страницы
(`docs\THEME.md`, `site\ui\README.md`).

`404.html` этого репозитория — копия страницы входа (так работают личные ссылки).
Своя страница ошибки (шапка шаблона, тема, язык) есть в репозитории `mini-apps`.

## Публикация

Правим `site\` в проекте → `.\publish_home.ps1` → через полминуты страница обновится.
Скрипт выкладывает всё содержимое папки рекурсивно, сам делает `404.html` из
`accounts/index.html` и **не трогает** `status.json`, если тот уже есть в репозитории
(его содержимое обновляет окно «2. Сервер»).

Репозиторий обязан называться ровно `dperegudov61.github.io` — только тогда Pages
отдаёт его с корня домена.

Раньше репозиторий звался `main-page`, поэтому страница жила по адресу `/main-page/`;
после переименования (23.11.2026) этот адрес отдаёт 404.
