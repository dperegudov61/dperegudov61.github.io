# ui — общий шаблон страниц проекта

Папка лежит рядом с главной страницей и отдаётся как **https://dperegudov61.github.io/ui/**.
Здесь в одном экземпляре живут шапка и настройки вида: тема, язык, кнопка аккаунта,
логотип-ссылка на главную. Страницы всех репозиториев (`dperegudov61.github.io`,
`AI-Human-Messenger`, `mini-apps`) подключают эти файлы по абсолютному адресу `/ui/…`,
поэтому правка шаблона меняет сразу весь сайт, а кнопки с одинаковым смыслом
выглядят одинаково.

## Что внутри

| файл | что это |
|---|---|
| `ui.js` | весь шаблон: тема, язык, словарь, шапка, связка с сервером (`/__prefs`) |
| `ui.css` | вид шапки (своя палитра `--ub-*`, тёмная и светлая) |
| `strings.tsv` | надписи самой шапки: «Главная», «Аккаунт», «Войти», «Тема», «Язык», названия языков |
| `logo.png` | круглый знак сайта для кнопки «домой» (32×32, из мастер-рисунка `ico\logo.png`: `tools\make_logo.ps1`); он же — значок вкладки `site\favicon.png` |

`ui.css` подключать не нужно — его добавляет сам `ui.js` из своей папки.

## Как подключить страницу

В `<head>`, **до** своих стилей и разметки (иначе будет вспышка чужой темы):

```html
<script src="/ui/ui.js" data-i18n="/путь/к/strings.tsv"></script>
```

В разметке — там, где должна стоять шапка:

```html
<div class="uibar" data-ui="bar"></div>
```

Если страница нашла сервер и знает токен — отдать настройки человека:

```js
UI.sync(base, token);      // тема и язык с сервера главнее кеша устройства
```

## Настройки на теге `<script>` (все необязательны)

| атрибут | по умолчанию | смысл |
|---|---|---|
| `data-i18n` | `strings.tsv` рядом со страницей | таблица надписей этой страницы |
| `data-home` | — | `"0"` — не показывать логотип-ссылку на главную |
| `data-account` | — | `"0"` — не показывать кнопку аккаунта (страницы входа и настроек) |
| `data-home-href` | `https://dperegudov61.github.io/` | куда ведёт логотип |
| `data-account-href` | `/account/` | куда ведёт имя вошедшего |
| `data-signin-href` | `/accounts/` | куда ведёт «Войти» |
| `data-logo` | `/ui/logo.png` | картинка логотипа |

Свои надписи страницы по-прежнему работают: `data-i18n="ключ"` в разметке,
`t('ключ', 'English fallback')` в коде. Таблицы шаблона и страницы **складываются**,
языки берутся из заголовков обеих.

## Шапка

Порядок: `[логотип] [растяжка] [тема] [язык] [аккаунт]`.

* **Логотип** — картинка `logo.png`, ведёт на главную (как значок Google).
* **Тема** — значок, по нажатию перебирает: 🌙 тёмная → ☀️ светлая → 🌗 как в системе.
* **Язык** — список, показывает две буквы (`en`, `ru`); полное название видно в подсказке.
  Смена языка перезагружает страницу — надписи в разметке собираются заново.
* **Аккаунт** — имя с точкой состояния (зелёная — сервер отвечает, красная — молчит,
  серая — не знаем) и ссылкой на `/account/`; без входа — «Войти» на `/accounts/`.
  На телефоне (уже 520 px) остаётся только точка, без имени.

`UI.online(true|false)` — страница сообщает, отвечает ли сервер (так точка и меняется).

## Новый элемент шаблона

**На всех страницах сразу** — добавить функцию рядом с `themeNode()`/`langNode()`
и вставить её в `renderBar()` в `ui.js`. Всё, что попало в `renderBar()`, появляется
везде, где подключён `data-ui="bar"`.

**Только на одной странице** — страница зовёт `UI.add`:

```js
UI.add({ icon: '🔔', text: t('chat.bell', 'Alerts'), title: '…', href: '#', slot: 'theme' });
```

`slot` — куда встать: `logo`, `theme`, `lang`, `account` (перед этой кнопкой) или `end`.
Текст и заголовок могут быть функциями — тогда они пересчитываются при смене языка.

## Новый язык

Добавить столбец в `strings.tsv` шаблона и в `strings.tsv` страниц — код не меняется:
список языков в шапке строится по заголовку таблицы. Название языка в списке —
ключ `lang.<код>` (например, `lang.kk`).

## Правила

* Шаблон — **один**. Не копировать `ui.js` в другие репозитории: именно из-за копий
  кнопки когда-то разошлись. Сайт один домен, `/ui/ui.js` виден всем страницам.
* Файл `theme.js` в трёх папках — пустая обёртка для страниц из кэша браузера;
  новым страницам он не нужен.
* GitHub Pages держит файл в кэше браузера до 10 минут: правка шаблона видна не сразу.
* Шаблон должен переживать своё отсутствие: если `ui.js` не загрузился, страница
  показывает английские надписи из разметки и тёмную тему. Не переносить в шаблон
  то, без чего страница не работает.
* Проверки: `node tools\theme_test.js`, `node tools\i18n_test.js`, `node tools\jscheck.js`.
